## TICKET-08 · Инфраструктура: `httpClient` и общие утилиты

**Тип:** Improvement
**Приоритет:** Low
**Компоненты:** `shared/lib/httpClient.ts`

### Краткое описание
Два небольших улучшения в общей инфраструктуре: уточнён тип возвращаемого значения `httpClient<T>` (устранены ложные TS-ошибки), добавлена `httpClientAction<T>()` для мутаций без выброса.

### Что было сделано
- `data` в ответе `httpClient` теперь типизирована как `T` (не `T | undefined`) — клиенты больше не требуют лишних null-guard
- `httpClientAction<T>()` — новый клиент для мутаций, перехватывает 403/422 и `success=false` и возвращает `ActionResult` вместо выброса

### Context
`httpClient` всегда выбрасывает при ошибке, поэтому `data` на успешном пути не может быть `undefined`. Прежняя типизация (`data?: T`) вынуждала писать ненужные guard-проверки везде в кодовой базе.

### Steps
1. Уточнить сигнатуру `httpClient.ts` (`data: T` вместо `data?: T`)
2. Добавить `httpClientAction<T>()` с перехватом ошибок

### Definition of Done
- [ ] Callers, деструктурирующие `{ data }`, больше не получают TS-ошибок
- [ ] `httpClientAction` используется в `features/agents` для мутаций
- [ ] Поведение в рантайме не изменилось
